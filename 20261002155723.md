# Vim Basics

## Navigation

    h j k l       links / runter / hoch / rechts
    gg            Dateianfang
    G             Dateiende
    20G           Zeile 20
    0             Zeilenanfang
    $             Zeilenende

    Ctrl+d        halbe Seite runter
    Ctrl+u        halbe Seite hoch

## Bearbeiten

    i             Insert Mode
    o             neue Zeile darunter
    O             neue Zeile darüber

    dd            Zeile löschen
    yy            Zeile kopieren
    p             einfügen

    u             Undo
    Ctrl+r        Redo

## Visual Mode

    V             ganze Zeilen markieren
    >             einrücken
    <             ausrücken
    gv            letzte Auswahl erneut markieren

## Suchen

    /text         suchen
    n             nächster Treffer
    N             vorheriger Treffer

## Einstellungen

    :set sw=4
    :set ts=4
    :set expandtab
